## What I'm doing

Most SMEs are still running on spreadsheets and guesswork. I build backend systems and AI agents that give them the kind of operational intelligence only large enterprises could afford — without the enterprise price tag or complexity.

Right now that means building an **AI-native ERP**: the data layer, the APIs, and the agents that sit on top and actually do the work, not just dashboard it.

<br/>

## How I think about it

- **Boring infrastructure, exciting outcomes.** The best backend work is invisible — it just means the product never breaks when it matters.
- **Agents should finish tasks, not just answer questions.** I'm more interested in AI that takes action inside a workflow than AI that chats about one.
- **Ship for the one real user before the ten imagined ones.** Production feedback beats roadmap speculation, every time.
